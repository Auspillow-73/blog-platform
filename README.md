# 📝 Blog Platform with Comments

A full-stack blogging platform built with **Node.js**, **Express**, **SQLite**, and vanilla **JavaScript**. Users can register, log in, create blog posts, and interact through comments.

---

## 🚀 Features

- **User Authentication** — Secure registration & login with JWT tokens
- **Blog Posts** — Create, edit, and delete your own posts
- **Comments** — Comment on any post
- **RESTful API** — Clean backend architecture
- **SQLite Database** — File-based, zero configuration

---

## 🛠️ Tech Stack

| Layer | Technology |
|-------|-----------|
| Backend | Node.js, Express |
| Database | SQLite3 |
| Auth | JWT, bcryptjs |
| Frontend | HTML, CSS, JavaScript |
